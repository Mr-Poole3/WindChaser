# Phase 3 PRD: 智能体验 — WindChaser

## Problem Statement

前两个 Phase 做完了基础骑行和传感器接入。但三个体验问题尚未解决：(1) 红灯停车时不会自动暂停，拉低了平均速度和统计数据；(2) GPS 全程高精度 + ActivityKit 高频锁屏刷新让电池在 3-4 小时长距离骑行中吃不消；(3) 历史记录列表只能线性浏览，看不到骑行趋势和频率；(4) 用户想跟着别人分享的路线骑行时，只能盲骑——没有路线预览和偏离提示。

## Solution

四个独立功能交付：自动暂停（消除等红灯手动操作）、电池智能降频（巡航时自动降级 GPS 精度和刷新频率，冲刺时全速恢复）、日历热力图（可视化骑行频率和趋势）、路书导入与偏航提醒（在地图上显示预告路线，偏离时弹出警告）。

## User Stories

### 自动暂停
1. 作为一名骑手，当我在红灯前停车超过 5 秒后，骑行自动暂停，不需要手动去点"暂停"按钮
2. 作为一名骑手，绿灯后我开始移动，骑行自动恢复记录，速度、里程和计时无缝衔接
3. 作为一名骑手，自动暂停和手动暂停互不冲突——自动暂停状态下我也可以手动恢复
4. 作为一名骑手，我在设置里可以开关自动暂停功能并调整触发等待时间（3s / 5s / 10s）

### 电池智能降频
5. 作为一名骑手，在长直平路巡航超过 2 分钟时，App 自动降低 GPS 精度（从高精度降到 10 米精度），降低锁屏刷新频率，帮我省电
6. 作为一名骑手，当我开始加速、减速、转弯或进入爬坡时，App 立刻恢复到最高精度和全速刷新，确保数据不受影响
7. 作为一名骑手，我在设置里可以看到当前电池优化状态（全速/降频），并可以选择关闭自动降频

### 日历热力图
8. 作为一名骑手，我在历史记录页面可以切换到日历视图，以热力图的方式查看每个月的骑行频率
9. 作为一名骑手，热力图上每个日期格子的颜色深浅对应骑行距离——骑行越长颜色越深，一眼看出这个月骑得多不多
10. 作为一名骑手，点击日历上的某个日期可以看到该日骑行的摘要卡片

### 路书导入
11. 作为一名骑手，我可以在 App 内导入 GPX 路书文件（从朋友分享的路线、赛事官方路线获取），无需网络
12. 作为一名骑手，地图上同时显示"预告路线"（虚线，不同颜色）和"已骑行轨迹"（实线），我能清楚看到前方路线和已完成的进度
13. 作为一名骑手，当我偏离路书超过设定距离时，浮层上弹出一个视觉提示图标，提醒我回到了错误的路线（需要网络）
14. 作为一名骑手，我可以在设置里调整偏航提醒的触发距离（50m / 100m / 200m）

## Implementation Decisions

### 自动暂停

- **检测器**：复用 SensorEngine 的 `CLLocation.speed` 属性。连续 N 秒（默认 5 秒）速度 < 1.5 km/h 触发自动暂停。速度 > 3 km/h 持续 3 秒触发自动恢复。
- **与手动暂停的关系**：自动暂停状态下 `.paused` 与手动暂停状态一致。区别在于触发源不同（自动 vs 手动）。自动暂停后用户手动恢复，之后自动暂停继续生效。
- **配置**：设置页增加"自动暂停"开关 + 触发等待时间滑块（3/5/10 秒）。

### 电池智能降频

- **D 方案全组合**：
  - GPS 精度降级：平路巡航且速度方差 < 3 km/h 持续 2 分钟 → 从 `kCLLocationAccuracyBestForNavigation` 降到 `kCLLocationAccuracyNearestTenMeters`
  - distanceFilter 调大：巡航时 `distanceFilter` 从 0（每次更新都给）调到 10m 以上
  - ActivityKit 刷新拉长：巡航时锁屏更新间隔从 1 秒调到 5 秒
  - 恢复条件：加速度突变（delta speed > 5 km/h within 2s）、转弯（heading 变化 > 15° in 2s）、气压计检测到爬坡（altitude delta > 2m in 10s）→ 全速恢复

- **状态机**：
```
.fullPower ←→ .powerSaving
    ↑              ↓
 恢复条件      巡航 2min + 速度方差 < 3 km/h
```

- **UI 指示**：仪表盘右上角增加一个电池叶子图标表示当前状态，用户可在设置中关闭自动降频。

### 日历热力图

- **UI**：`UICollectionView` 或 SwiftUI `LazyVGrid`，7 列（周一到周日），按月份分段。
- **颜色映射**：0km（灰白）→ 10km（淡绿）→ 50km（中绿）→ 100km+（深绿）。
- **数据源**：从所有 `.ridesqlite` 文件中查询每日累计骑行距离（`SELECT SUM(distance) FROM rides GROUP BY date`）。

### 路书导入

- **导入**：`UIDocumentPickerViewController` 选择 `.gpx` 文件。解析 GPX XML 提取 `<trkpt lat=... lon=...>` 或 `<rtept>` 坐标序列。
- **无网络可用**：GPX 解析和轨迹绘制无需网络。计算偏航需要网络（需要实时路网数据或在线地图匹配）。
- **地图图层**：
  - 已骑行轨迹（实线，Phase 1 颜色）——来自实时 GPS
  - 预告路线（虚线，蓝色或淡紫色）——来自 GPX 路书
- **偏航检测**：计算当前位置点到路书轨迹上最近点的距离。> 阈值（默认 100m）触发偏航。提醒为浮层顶部弹出一个非阻塞的旗帜图标（不打断骑行）。

## Testing Decisions

- 自动暂停触发/恢复逻辑（模拟速度序列）
- 电池降频状态机转换逻辑（模拟速度方差、加速度等条件）
- 日历热力图颜色映射边界值
- GPX 解析正确性（多种 GPX 格式变体的兼容性）
- 偏航距离计算正确性（点到轨迹最近点算法）

## Out of Scope

- 在线路线推荐/热门路书库
- 社交功能（分享路线、排行榜）
- 坡度/爬升预测（基于路书的预估）
- Watch 独立码表（Phase 4）
- 语音播报（"前方 50 米右转"）

## Further Notes

- 电池降频策略的核心是"感知场景变化"——加速度、方向、海拔变化率三个信号共同判断"巡航 vs 动态骑行"
- 路书导入后的预告路线不参与轨迹记录（不写入 SQLite 的 samples 表）
- 偏航提醒需要网络——无网络时路书仍可显示，但没有偏航检测
